# センサーモデル検証計画

## 目的
実際のセンサーデータとシミュレーションのセンサーモデルが一致しているか検証する。

## シミュレーションで実装されているモデル

### センサーモデル詳細
| センサー | 物理モデル | 座標系変換 | ノイズ特性 |
|---------|-----------|----------|----------|
| **加速度計** | 比力 f = a - g（運動加速度 - 重力） | 世界座標 → 機体座標（回転行列R） | ホワイト + ピンク + アラン偏差 |
| **ジャイロ** | 角速度 ω = [ωx, ωy, ωz] | 機体座標系での角速度 | ホワイト + ピンク + アラン偏差 |
| **磁気計** | 地磁気ベクトル（北向き） | 世界座標 → 機体座標（回転行列R） | ホワイト + ピンク |
| **気圧計** | 気圧高度（標準大気モデル） | 高度 → 気圧変換 | ホワイト + アラン偏差 |

### 座標系定義
- **世界座標系（NED）**: North(+X), East(+Y), Down(+Z)
- **機体座標系**: Forward(+X), Right(+Y), Down(+Z)
- **回転順序**: ZYX（Yaw→Pitch→Roll）
- **四元数**: [w, x, y, z] スカラー先頭

## 🎯 推奨検証運動パターン

### 【レベル1】基本静止・姿勢確認（必須）

#### 1-1. 完全静止（水平）stillness 
**目的**: 重力ベクトル・バイアス・ノイズレベル確認
```
運動: 水平面に静置（5分以上）
期待値:
  accel: [0, 0, +9.81] m/s² （機体座標系でZ軸下向き＝重力）
  gyro:  [0, 0, 0] deg/s
  mag:   [北成分, 東成分, 下向き成分] （地域の地磁気に依存）
  baro:  一定値（標高に依存）
検証項目:
  - 加速度計Z軸が 9.81 m/s² に収束するか
  - ジャイロの静止時ドリフト（バイアス）
  - 各センサーのノイズ標準偏差
  - バイアス推定の収束時間
```

#### 1-2. 姿勢静止（Roll = +90°）Tilt right
**目的**: 重力ベクトルの座標変換確認
```
運動: デバイスを右に90°傾けて静置（1分以上）
期待値:
  accel: [0, +9.81, 0] m/s² （重力がY軸方向に）
  gyro:  [0, 0, 0] deg/s
  mag:   方位による（傾きに応じて変化）
検証項目:
  - 回転行列による重力変換が正しいか
  - Roll角推定が±90°付近に収束するか
```

#### 1-3. 姿勢静止（Pitch = +45°）Upward
**目的**: ピッチ角での重力分解確認
```
運動: デバイスを前方に45°傾けて静置（1分以上）
期待値:
  accel: [+9.81*sin(45°), 0, +9.81*cos(45°)] ≈ [+6.94, 0, +6.94] m/s²
  gyro:  [0, 0, 0] deg/s
検証項目:
  - ピッチ角45°での加速度成分分解
  - Pitch角推定の精度
```

#### 1-4. 姿勢静止（Yaw回転: 0° → 90° → 180° → 270° → 0°）Clockwise
**目的**: 磁気計の方位角依存性確認
```
運動: デバイスを水平に保ち、90°ずつ回転して各30秒静止
期待値:
  accel: [0, 0, +9.81] m/s² （常に一定）
  gyro:  [0, 0, 0] deg/s （静止時）
  mag:   [Mx, My, Mz] の(Mx, My)が円軌道を描く
検証項目:
  - 磁気計の水平成分が円を描くか（ハードアイアン・ソフトアイアン補正確認）
  - Yaw角推定が 0°, 90°, 180°, 270° に収束するか
```

---

### 【レベル2】回転運動（ジャイロ・姿勢積分確認）

#### 2-1. 純粋ロール回転（Roll軸周り: 右回り1周）Right rotation
**目的**: ロール軸ジャイロと姿勢積分確認
```
運動: デバイスをX軸（前方軸）周りに右回りで1周（約5秒で360°）
      → 元の姿勢に戻る
期待値:
  gyro_x: +72 deg/s （等速回転時、360°/5s = 72 deg/s）
  gyro_y, gyro_z: 0 deg/s
  積分後のRoll角: 0° → 360° → 0° （元に戻る）
検証項目:
  - ジャイロX軸の積分値が360°になるか
  - 姿勢推定が元の状態に戻るか（積分誤差確認）
```

#### 2-2. 純粋ピッチ回転（Pitch軸周り: 前後1往復）Upward and downward
**目的**: ピッチ軸ジャイロ確認
```
運動: デバイスをY軸（右方向軸）周りに前後に揺らす
      水平 → 前45° → 水平 → 後45° → 水平（各遷移2秒）
期待値:
  gyro_y: +22.5 deg/s（前傾時）、-22.5 deg/s（後傾時）
  gyro_x, gyro_z: 0 deg/s
検証項目:
  - ジャイロY軸の符号と大きさ
  - ピッチ角推定が±45°に達するか
```

#### 2-3. 純粋ヨー回転（右回り1周・等角速度）One rotation left and right
**目的**: ヨー軸ジャイロと磁気計の整合性確認 
```
運動: デバイスを水平に保ち、Z軸（下向き軸）周りに右回り1周（10秒で360°）
期待値:
  gyro_z: +36 deg/s （等速回転時、360°/10s = 36 deg/s）
  gyro_x, gyro_y: 0 deg/s
  mag:   水平成分が円軌道を1周
  積分後のYaw角: 0° → 360° → 0°
検証項目:
  - ジャイロZ軸の積分値が360°になるか
  - 磁気計から推定したYaw角がジャイロ積分と一致するか
```

---

### 【レベル3】並進運動（加速度計・気圧計確認）Up and down

#### 3-1. 垂直上下運動（エレベーター移動）
**目的**: 気圧計と加速度計Z軸の整合性確認
```
運動: エレベーターで上昇・下降（各階約3m、速度約1 m/s）
      静止(2s) → 上昇開始 → 等速上昇(3s) → 減速停止(1s) → 静止(2s)
期待値:
  上昇開始時: accel_z < +9.81 m/s²（下向き加速度減少）
  等速上昇時: accel_z ≈ +9.81 m/s²（重力のみ）
  減速停止時: accel_z > +9.81 m/s²（下向き加速度増加）
  baro: 気圧減少（高度上昇に対応、約12 Pa/m）
検証項目:
  - 加速度計Z軸の過渡応答
  - 気圧高度の変化量（実測3m vs 気圧換算高度）
  - 気圧計の時定数・遅延
```

#### 3-2. 水平直線加速（前進・停止）Back and forth
**目的**: 加速度計X軸（前方向）の確認
```
運動: デバイスを水平に保ち、前方に加速して移動・停止
      静止(2s) → 加速(1s, ~1 m/s²) → 等速(2s) → 減速(1s) → 静止(2s)
期待値:
  加速時: accel_x ≈ -1.0 m/s²（機体が前進=慣性力が後ろ向き）
  等速時: accel_x ≈ 0 m/s²
  減速時: accel_x ≈ +1.0 m/s²（慣性力が前向き）
  gyro: 回転しないため [0, 0, 0]
検証項目:
  - 加速度計の符号（慣性力 vs 真の加速度）
  - 速度積分値が実測距離と一致するか
```

### 【レベル4】複合運動（シミュレーションと同一パターン）

#### 4-1. 水平円運動（右回り・等速）⭐ 最重要
**目的**: シミュレーションの `circular` モードと直接比較
```
運動: デバイスを水平に保ち、半径 R = 0.5m の円軌道を右回りで等角速度移動
      周期 T = 10秒 → 角速度 ω = 36 deg/s = 0.628 rad/s
      向心加速度 a_c = ω²R = 0.197 m/s² （内向き）
期待値:
  gyro_z: +36 deg/s （右回り）
  accel（機体座標系、常に接線方向を向く場合）:
    - 等速なら接線加速度 = 0、向心加速度が横方向に現れる
    - accel_y（右向き）: 左向き向心力 = -0.197 m/s²（機体が円の接線方向を向く場合）
  mag: 水平成分が円軌道
  baro: 一定（高度変化なし）
検証項目:
  - ジャイロZ軸が理論角速度 36 deg/s と一致するか
  - 加速度計の向心加速度成分が ω²R と一致するか
  - 磁気計から推定したヨー角がジャイロ積分と一致するか
  - フィルタ推定位置が円軌道を描くか
```
**シミュレーション対応パラメータ**:
```matlab
params.motion.circular.radius = 0.5;     % m
params.motion.circular.omega = 0.628;    % rad/s (= 36 deg/s)
params.static_time = 5;                  % 最初5秒静止
params.motion.circular.accel_time = 5;   % 5秒でソフトスタート
```

#### 4-2. 円運動 + ロール/ピッチ振動
**目的**: シミュレーションの振動モデル確認
```
運動: 4-1の円運動をしながら、デバイスを前後・左右に傾ける
      Roll振動: 振幅 ±15°、周期 10秒
      Pitch振動: 振幅 ±10°、周期 8秒
期待値:
  複合角速度（ジャイロ）:
    - gyro_x: ±15° * 2π/10s ≈ ±9.4 deg/s（Roll振動）
    - gyro_y: ±10° * 2π/8s ≈ ±7.9 deg/s（Pitch振動）
    - gyro_z: +36 deg/s（Yaw回転）+ ロール/ピッチによるカップリング
  accel: 重力成分が振動で変化
検証項目:
  - ジャイロの3軸成分が独立に測定されているか
  - 姿勢推定がロール/ピッチ振動を追従するか
```
**シミュレーション対応パラメータ**:
```matlab
params.motion.oscillation.roll_amplitude = deg2rad(15);
params.motion.oscillation.roll_period = 10;
params.motion.oscillation.pitch_amplitude = deg2rad(10);
params.motion.oscillation.pitch_period = 8;
params.motion.oscillation.soft_start_time = 3;
```

#### 4-3. ランダムウォーク（前進・蛇行）
**目的**: シミュレーションの `random_walk` モードと比較
```
運動: デバイスを前方に移動させながら、ランダムに方向転換
      前進速度: 0.5 ± 0.1 m/s（ランダム変動）
      ヨー角速度: ±10 deg/s のランダム変動
      実施時間: 60秒以上
期待値:
  gyro_z: ランダムな方向転換角速度
  accel_x: 前進加速度（ノイズ重畳）
  mag: ヨー角に応じた磁場変化
  位置推定: 前進軌跡（蛇行）
検証項目:
  - 統計的なノイズ特性（標準偏差、ピンクノイズ、アラン偏差）
  - フィルタの追従性能
```

```
  フィルタ: 外れ値として検出または適切に処理
検証項目:
  - センサー範囲（±16g など）内か
  - 外れ値判定閾値が適切か
```

## 📊 検証手順

### ステップ1: 基本静止テスト（レベル1）
1. `read_sensor_data.py` で実センサーデータ取得（各パターン1分以上）
2. シミュレーション `params.motion_type = 'stationary'` で同等データ生成
3. 比較:
   - 平均値（重力、バイアス）
   - 標準偏差（ノイズレベル）
   - パワースペクトル（ピンクノイズ確認）

### ステップ2: 回転運動テスト（レベル2）
1. 実センサー: ロール/ピッチ/ヨー回転を記録
2. シミュレーション: 同じ角速度・振幅で生成
3. 比較:
   - ジャイロ積分値 vs 実測角度
   - 姿勢推定精度（Roll/Pitch/Yaw）
   - 磁気計とジャイロの整合性

### ステップ3: 円運動テスト（レベル4-1）⭐
1. 実センサー: 半径0.5m、周期10秒の円運動を記録（3周以上）
2. シミュレーション: `circular` モードで同じパラメータ設定
3. 比較:
   - 向心加速度（理論値 0.197 m/s² vs 実測）
   - ジャイロZ軸（理論値 36 deg/s vs 実測）
   - フィルタ推定軌跡（円の半径・形状）
   - 位置誤差のRMS

### ステップ4: 統計的検証
各運動パターンで以下を比較:
```matlab
% 実データとシミュレーションの統計量比較
real_data = load('sensor_data_YYYYMMDD_HHMMSS.csv');
sim_data = load('GenerateData/sensor_data.csv');

% センサーごとに比較
sensors = {'accel_x', 'accel_y', 'accel_z', 'gyro_x', 'gyro_y', 'gyro_z', ...
           'mag_x', 'mag_y', 'mag_z', 'baro'};
for i = 1:length(sensors)
    compare_sensor_statistics(real_data, sim_data, sensors{i});
end

function compare_sensor_statistics(real, sim, sensor_name)
    fprintf('=== %s ===\n', sensor_name);
    fprintf('平均値:   実%.4f vs シミュ%.4f (差%.4f)\n', ...
            mean(real.(sensor_name)), mean(sim.(sensor_name)), ...
            abs(mean(real.(sensor_name)) - mean(sim.(sensor_name))));
    fprintf('標準偏差: 実%.4f vs シミュ%.4f (比%.2f)\n', ...
            std(real.(sensor_name)), std(sim.(sensor_name)), ...
            std(real.(sensor_name)) / std(sim.(sensor_name)));
    % パワースペクトル密度（PSD）比較
    [psd_real, f] = pwelch(real.(sensor_name));
    [psd_sim, ~] = pwelch(sim.(sensor_name));
    figure; loglog(f, psd_real, f, psd_sim);
    legend('実データ', 'シミュレーション');
    title(sprintf('%s パワースペクトル密度', sensor_name));
end
```

## 🎓 期待される結果

### モデルが一致している場合
- [ ] 静止時の重力ベクトルが ±5% 以内で一致（9.81 m/s²）
- [ ] ジャイロの積分値が実測角度と ±2° 以内で一致
- [ ] 円運動の向心加速度が理論値と ±10% 以内で一致
- [ ] 磁気計から推定したヨー角とジャイロ積分が ±5° 以内で一致
- [ ] 気圧高度の変化量が実測高度と ±0.5m 以内で一致
- [ ] ノイズ標準偏差が設定値と ±20% 以内で一致
- [ ] パワースペクトル密度の傾き（ピンクノイズ: -10 dB/decade）が一致

### モデルが不一致の場合の原因候補
1. **座標系定義の違い**: NED vs ENU、機体軸の定義
2. **回転行列の順序**: ZYX vs XYZ、四元数の符号
3. **センサー軸の割り当て**: デバイスの物理的な取り付け方向
4. **キャリブレーション不足**: 加速度計/磁気計のオフセット・スケール
5. **ノイズモデルの違い**: ホワイトノイズ vs ピンクノイズ vs アラン偏差
6. **時定数の違い**: センサーのサンプリングレート、フィルタ帯域

## 参考: シミュレーションパラメータ一覧

現在の設定値（`config_params.m`）:
```matlab
% ノイズレベル (1σ)
params.noise.accel_std = 0.1;       % m/s²
params.noise.gyro_std = 0.5;        % deg/s
params.noise.mag_std = 5.0;         % μT
params.noise.baro_std = 2.0;        % m (気圧高度換算)
params.noise.gps_std = 1.0;         % m

% ピンクノイズ
params.noise.accel_pink_std = 0.2;  % m/s²
params.noise.gyro_pink_std = 0.2;   % deg/s

% アラン偏差（バイアス不安定性）
params.noise.gyro_allan_std = 0.5;  % deg/s
params.noise.baro_allan_std = 1.0;  % m
```

実デバイスのスペックシートと比較してパラメータ調整が必要です。
