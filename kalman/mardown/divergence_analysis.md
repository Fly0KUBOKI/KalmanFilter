# 推定発散の原因分析レポート

## 実行日時
2025年12月6日

## 発散の症状

### 観測された問題
- **時刻**: t=145～157秒の区間で顕著な発散
- **最大位置誤差**: 7.37m (t=155.34s)
- **最大速度誤差**: 2.614m/s (t=146.22s)

### 具体的な発散パターン

#### 速度発散
```
t=146s付近:
推定速度: vx=-2.8m/s, vy=-0.18m/s, vz=-0.12m/s
真値速度: vx=-0.37m/s, vy=-0.59m/s, vz=0.00m/s
誤差:     vx=-2.43m/s (約7倍の誤差)
```

#### 姿勢発散（**根本原因**）
```
時刻[s] | Roll(推定/真値)  | Pitch(推定/真値) | Yaw(推定/真値)
--------|------------------|------------------|-----------------
140.0   | -183.6 / -171.3  |  132.0 / -102.8  |  9866.0 /  9857.2
146.0   |  -91.8 /  165.5  |  532.1 /   99.3  |  8463.8 /  8482.1
149.0   | -645.4 / -271.3  |  312.9 / -162.8  |  7739.0 /  7794.5
150.0   | -542.0 / -171.3  |  358.4 / -102.8  |  7545.5 /  7565.3
```

**重大な問題点**:
- Roll: -645度まで発散（真値は±271度の範囲）
- Pitch: 665度まで発散（真値は±164度の範囲）
- 周期的な振動パターンを示す（ジンバルロック/符号反転の可能性）

## 発散メカニズム

### 1. 姿勢推定の発散
**原因**: 
- 加速度計更新（`update_accel`）で過剰な姿勢補正
- クォータニオンの符号反転問題
- ジンバルロック近傍での不安定性

### 2. 速度推定への波及
**メカニズム**:
```
姿勢発散 → 回転行列Rbが誤る → a_world = Rb * a_body が誤る
→ 速度積分 v = v + (a_world + g)*dt が誤った方向に進む
→ 速度が発散
```

**具体例** (t=146s):
- 真の姿勢: Roll=165.5°, Pitch=99.3°
- 推定姿勢: Roll=-91.8°, Pitch=532.1°（約180度のずれ）
- 結果: 加速度ベクトルが逆向きに変換され、速度が-2.8m/sに発散

### 3. 位置推定への波及
```
速度発散 → 位置積分 p = p + v*dt が誤る → 位置が発散
```

## 発散の根本原因

### 1. **姿勢更新ゲインが過大**
- `update_accel`でのカルマンゲインが大きすぎる
- ノイズや外れ値に過剰反応

### 2. **速度減衰の逆効果**
- 現在の実装（`velocity_damping = 0.15`）は**症状を悪化させる**:
  - 姿勢が誤っているのに、その誤った姿勢で計算された速度を減衰させる
  - 正しい速度への収束を妨げる

### 3. **クォータニオン正規化の問題**
- 大きな姿勢誤差が蓄積すると、クォータニオンの符号反転が発生
- 180度反転した姿勢が定常化する

## 推奨される対策

### 優先度1: 姿勢更新の安定化
1. **`update_accel`のゲイン制限**
   - R行列（観測ノイズ）を大きくして姿勢更新を緩和
   - 現在の`R_floor = 0.1`を`0.5`～`1.0`に増加

2. **姿勢更新の周波数を下げる**
   - `freq_accel`を4から10または20に変更
   - 頻繁な更新が振動を引き起こしている

3. **姿勢変化の制限**
   - 1ステップあたりの姿勢変化を`±10度`以内に制限

### 優先度2: 速度減衰の無効化または条件付き適用
```matlab
% 速度減衰を無効化
obj.velocity_damping = 0.0;

% または、姿勢が安定している時のみ適用
if norm(euler_error) < deg2rad(10)
    obj.v = obj.v * (1.0 - obj.velocity_damping * obj.dt);
end
```

### 優先度3: クォータニオンの符号チェック
```matlab
% クォータニオンの符号を前ステップと整合させる
if dot(q_new, q_prev) < 0
    q_new = -q_new;
end
```

## 診断情報の追加（実装済み）
以下の情報を`estimation.csv`に追加しました：
- `P_px, P_py, P_pz, P_vx, P_vy, P_vz`: 共分散の対角成分
- `zupt_active`: ZUPT（静止検出）が有効か
- `a_filt_x, a_filt_y, a_filt_z`: フィルタ済み加速度

これにより、次回実行時に発散の詳細なメカニズムを追跡可能。

## 結論
**速度減衰は発散の原因ではなく、姿勢推定の発散が根本原因**。
姿勢更新を安定化させることで、速度・位置推定も自動的に改善されます。
