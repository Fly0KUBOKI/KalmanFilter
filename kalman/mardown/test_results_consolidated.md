## 発散問題の分析

### 発散の症状（2025年12月6日）

#### 観測された問題
- **時刻**: t=145～157秒の区間で顕著な発散
- **最大位置誤差**: 7.37m (t=155.34s)
- **最大速度誤差**: 2.614m/s (t=146.22s)

#### 姿勢発散（根本原因）
```
時刻[s] | Roll(推定/真値)  | Pitch(推定/真値) | Yaw(推定/真値)
--------|------------------|------------------|-----------------
140.0   | -183.6 / -171.3  |  132.0 / -102.8  |  9866.0 /  9857.2
146.0   |  -91.8 /  165.5  |  532.1 /   99.3  |  8463.8 /  8482.1
149.0   | -645.4 / -271.3  |  312.9 / -162.8  |  7739.0 /  7794.5
150.0   | -542.0 / -171.3  |  358.4 / -102.8  |  7545.5 /  7565.3
```

**重大な問題点**:
- Roll: -645度まで発散（真値は±271度の範囲）
- Pitch: 665度まで発散（真値は±164度の範囲）
- 周期的な振動パターンを示す（ジンバルロック/符号反転の可能性）

### 発散メカニズム

#### 1. 姿勢推定の発散
**原因**: 
- 加速度計更新（`update_accel`）で過剰な姿勢補正
- クォータニオンの符号反転問題
- ジンバルロック近傍での不安定性

#### 2. 速度推定への波及
```
姿勢発散 → 回転行列Rbが誤る → a_world = Rb * a_body が誤る
→ 速度積分 v = v + (a_world + g)*dt が誤った方向に進む
→ 速度が発散
```

#### 3. 位置推定への波及
```
速度発散 → 位置積分 p = p + v*dt が誤る → 位置が発散
```

### 中盤発散の詳細解析

#### 全体統計
- **位置誤差**: 平均=1.84m, 最大=11.27m, 標準偏差=2.53m
- **速度誤差**: 平均=0.694m/s, 最大=2.810m/s, 標準偏差=0.763m/s
- **姿勢誤差**: 平均=98.12deg, 最大=275.87deg, 標準偏差=53.26deg

#### 最大発散区間（120-130秒）
- 位置誤差: 平均=7.66m, **最大=9.51m**
- 速度誤差: 平均=2.460m/s, **最大=2.597m/s**
- 姿勢誤差: 平均=181.96deg, **最大=275.87deg** ← ピーク
- Roll平均誤差: 87.2度, 最大: 180.0度
- Pitch平均誤差: 102.4度, 最大: 180.0度
- **姿勢がほぼ180度反転している状態**

### static_time延長による発散抑制の検証

#### 変更内容
```matlab
params.static_time = 0.5;  // 変更前
params.static_time = 5.0;  // 変更後 (10倍)
```

#### static_timeの役割

1. **ノイズパラメータの推定**
   - 静止期間（0-static_time秒）のセンサーデータからノイズを推定
   - より多くのサンプルで約3.16倍精度向上

2. **初期姿勢の推定**
   - 静止期間の加速度平均から初期Roll/Pitchを計算
   - より多くのサンプルでノイズが平均化され、初期姿勢推定が安定

#### 期待される効果

1. **初期共分散Pの適切な設定**: ノイズ推定精度向上により、Qmatrix、Rmatrixの初期値が改善
2. **初期姿勢誤差の低減**: Roll/Pitch推定がより正確になる
3. **初回update_accel時のゲイン適正化**: 初期Pが過大 → 過大なKalman gain → 姿勢ジャンプの抑制

### 推奨される対策

#### 優先度1: 姿勢更新の安定化
1. **`update_accel`のゲイン制限**
   - R行列（観測ノイズ）を大きくして姿勢更新を緩和
   - 現在の`R_floor = 0.1`を`0.5`～`1.0`に増加

2. **姿勢更新の周波数を下げる**
   - `freq_accel`を4から10または20に変更
   - 頻繁な更新が振動を引き起こしている

3. **姿勢変化の制限**
   - 1ステップあたりの姿勢変化を`±10度`以内に制限

#### 優先度2: 速度減衰の無効化または条件付き適用

## クイックテスト結果

### C++実装の段階的テスト（2025年12月12日）

| Test           | Pos RMSE | Roll RMSE | Pitch RMSE | Yaw RMSE |
|----------------|----------|-----------|------------|----------|
| All MATLAB     | 0.74 m   | 0.29°     | 0.37°      | **1.66°** |
| Accel C++      | 0.76 m   | 0.23°     | 0.24°      | **0.91°** |
| Mag C++        | 0.73 m   | 0.27°     | 0.30°      | **0.88°** |
| GPS C++        | 0.58 m   | 0.28°     | 0.35°      | **1.61°** |
| Baro C++       | 0.93 m   | 0.30°     | 0.39°      | **1.72°** |
| **All C++**    | 0.79 m   | 0.28°     | 0.37°      | **0.85°** |

### 主な発見

1. **Yaw Error Analysis**
   - **MATLAB-only**: 1.66° (exceeds 1.0° threshold)
   - **Accel/Mag C++**: 0.85-0.91° (within threshold)
   - **GPS/Baro C++**: 1.61-1.72° (worse than MATLAB)

2. **Roll/Pitch Performance**
   - All implementations show excellent roll/pitch accuracy (0.23-0.39°)
   - Well within 1.0° threshold
   - No significant difference between MATLAB and C++

3. **Position Error**
   - GPS C++ shows best position accuracy (0.58 m)
   - Baro C++ shows worst (0.93 m)
   - MATLAB-only: 0.74 m (acceptable)

### 結論

1. **C++ Accel/Mag updates significantly improve yaw accuracy** (47% reduction: 1.66° → 0.85°)
2. **GPS/Baro C++ implementations are problematic** (increase errors)
3. **Optimal configuration**: Accel C++ + Mag C++ enabled, GPS/Baro disabled

## アラン分散の影響分析

### ユーザー仮説（2025年12月10日）

> Yaw軸は角速度のドリフトが影響しており、地磁気による補正が弱くなっているように見える

### テスト結果

#### MATLAB実装でのアラン分散の影響

| 設定 | Position RMSE | Yaw RMSE | Yaw Drift STD | 改善 |
|------|--------------|----------|---------------|------|
| **Allan ON** (baseline) | 2.35 m | **2.08°** | 2.07° | - |
| **Allan OFF** | 1.90 m | **1.08°** | 1.08° | **47.9%** |

### 重要な発見

1. **Yaw RMSE が約50%改善**
   - Allan ON: 2.08°
   - Allan OFF: 1.08°
   - **改善量: 0.99°** (47.9%改善)

2. **Yaw Drift STD も約50%改善**
   - Allan ON: 2.07°
   - Allan OFF: 1.08°
   - **改善量: 1.00°** (48.1%改善)

3. **Position精度も向上**
   - Allan ON: 2.35 m
   - Allan OFF: 1.90 m
   - 改善量: 0.45 m (19.1%改善)

### 問題のメカニズム

1. **アラン分散によるドリフト生成**
   - ジャイロセンサーに長期的なドリフトが追加される
   - `gyro_allan_std = 0.2 deg/s` がランダムウォーク的に蓄積

2. **Yaw推定への影響**
   - ドリフトが蓄積すると、Yaw角の誤差が時間とともに増大
   - 地磁気センサーによる補正では、このドリフトを完全には打ち消せない

3. **地磁気補正の限界**
   - 地磁気センサーは姿勢（Roll, Pitch, Yaw）を観測
   - しかし、ジャイロドリフトの蓄積速度が速いと補正が追いつかない
   - 結果として、Yaw誤差が2°程度まで拡大
