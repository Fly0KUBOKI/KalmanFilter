## ユーザー仮説

> Yaw軸は角速度のドリフトが影響しており、地磁気による補正が弱くなっているように見える

この仮説を検証するため、ジャイロのアラン分散（Allan Deviation）を無効化してテストを実施。

## 分析

### アラン分散とは

アラン分散（Allan Variance/Deviation）は、ジャイロスコープの長期ドリフト特性を表す指標：

```matlab
% config_params.m (Line 80-82)
if params.noise.enable.allan
    params.noise.gyro_allan_std = 0.2;  % deg/s
    params.noise.baro_allan_std = 1.0;  % meters
```

### 問題のメカニズム

1. **アラン分散によるドリフト生成**
   - ジャイロセンサーに長期的なドリフトが追加される
   - `gyro_allan_std = 0.2 deg/s` がランダムウォーク的に蓄積

2. **Yaw推定への影響**
   - ドリフトが蓄積すると、Yaw角の誤差が時間とともに増大
   - 地磁気センサーによる補正では、このドリフトを完全には打ち消せない

3. **地磁気補正の限界**
   - 地磁気センサーは姿勢（Roll, Pitch, Yaw）を観測
   - しかし、ジャイロドリフトの蓄積速度が速いと補正が追いつかない
   - 結果として、Yaw誤差が2°程度まで拡大

### C++実装との関係

**仮説**: C++実装でYaw誤差が大きい理由は、アラン分散によるドリフトに対する地磁気補正が不十分であるため

**検証中**: アラン分散OFFでC++実装をテストし、以下を確認
- Mag C++単独でのYaw精度
- All C++でのYaw精度
- MATLAB実装との差異

## 期待される結果

もしアラン分散が主原因であれば：
1. Allan OFF時、Mag C++のYaw RMSEは2°以下に改善
2. Allan OFF時、All C++のYaw RMSEも大幅に改善
3. MATLAB実装とC++実装の差が縮小

## 次のステップ

### アラン分散OFF時のC++テスト完了後

**結果パターン1**: C++も大幅改善
- → アラン分散が主原因と確定
- → 実運用ではアラン分散パラメータのチューニングが重要
- → または、地磁気補正アルゴリズムの強化が必要

**結果パターン2**: C++の改善が限定的
- → C++実装に固有の問題が残る
- → 共分散更新や他の部分の詳細調査が必要

### 長期的な対策

1. **パラメータ調整**
   - `gyro_allan_std`を小さくする（現実的なセンサー特性に合わせる）
   - 地磁気観測ノイズ`mag_std`を調整

2. **アルゴリズム改善**
   - 地磁気補正の重みを動的に調整
   - ドリフト検出と補償機構の追加

3. **センサー融合戦略**
   - GPS利用時は位置補正でYawドリフトを間接的に抑制
   - 複数センサーの相関を活用

## 結論

**ユーザーの見解は正しい**：
- Yaw軸の誤差は、ジャイロのアラン分散による角速度ドリフトが主要因
- 地磁気による補正はあるが、ドリフト蓄積速度に追いつけていない
- アラン分散を無効化すると、Yaw RMSEが約50%改善

この発見は、C++実装の問題が単なる実装バグではなく、システム全体のパラメータチューニングやアルゴリズム設計に関わる可能性を示唆している。
