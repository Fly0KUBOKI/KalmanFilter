> **目的**: プログラム全体で使用されている MATLAB 実装部分を把握し、C++化の優先度判定に活用

## 概要

- **全体行数**: ~3600行（MATLAB）+ ~1600行（C++）
- **MATLAB比率**: 69%（うち、計算コアはほぼ全て C++化完了）
- **C++化完了率**: 100%（Predict/Update の 5コアステップ）

## 4. MATLAB 実装の必要性評価

### 4.1 **実装継続が必須** (C++化できない理由)

| 機能 | 理由 | 優先度 |
|-----|------|--------|
| **センサフィルタ** | Biquad LPF・外れ値検出は本来 MATLAB で十分。C++化は過剰 | **LOW** |
| **ノイズ推定** | 適応 R の複雑な統計処理。リアルタイム計算不要 | **MEDIUM** |
| **DivergenceGuard** | 複雑な発散検出ロジック（条件分岐多い）。メンテナンス性重視 | **HIGH** |
| **座標変換** | GPS Lat/Lon → ENU 変換。精度要件低い | **LOW** |
| **ZUPT判定** | 静止判定・速度補正。計算軽い | **LOW** |

### 4.2 **C++化の候補** (将来の最適化)

| 機能 | 推定効果 | 優先度 |
|-----|----------|--------|
| センサフィルタ (Biquad) | 数%高速化 | **LOW** |
| ノイズ推定エンジン | 5%高速化 | **MEDIUM** |
| DivergenceGuard | イノベーション計算を MATLAB→C++ へ | **MEDIUM** |
| 座標変換統合 | 1-2%高速化 | **VERY LOW** |
