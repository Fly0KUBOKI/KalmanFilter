# ACCEL更新 ノイズ対応策 実装レポート

## 問題の概要
ノイズを導入したテスト環境で、加速度計更新（ACCEL更新）の出力に大きな振動が見られました：
- Roll/Pitch に1°程度の急激な変化が繰り返される（のこぎり波）
- 数千ステップに渡って大きな変化が継続
- フィルタの発散傾向が懸念される

## 実装した対応策

### 1. **AccelFilter クラスの新規作成**
**ファイル**: `KF/Utils/AccelFilter.m`

指数移動平均（EMA）フィルタと外れ値検出を備えた専用フィルタクラスを実装：
- **EMA平滑化**: 計測加速度に指数移動平均を適用
  - EMA係数 α = 0.3（デフォルト）
  - α が小さいほど平滑化が強い
  - $y_{new} = \alpha \cdot x + (1-\alpha) \cdot y_{old}$

- **外れ値検出**: 残差ノルムに基づいた3σ判定
  - 3σを超える値は外れ値と判定
  - 外れ値の場合は前回値を保持（更新スキップ）

- **ノイズ履歴**: 最新20サンプルの履歴をキュー管理
  - 動的なノイズレベル推定に使用

### 2. **ESKF クラスの改良**
**ファイル**: `ESKF/ESKF.m`

#### 加速度フィルタの初期化
```matlab
obj.accel_filter = AccelFilter(0.3, 20);
```

#### updateAccel メソッドの改良
- **外れ値のスキップ**: 外れ値判定後は更新を中止
- **大きな変化の検出と スケーリング**:
  - Roll/Pitch の変化が 1.0° 以上の場合：1/10 にスケーリング
  - 変化の大きさに応じた適応的ゲイン制限

- **適応的ゲイン**:
  ```matlab
  if roll_diff > 0.5 || pitch_diff > 0.5
      adaptive_gain = 1.0 / (1.0 + max(roll_diff, pitch_diff) / 2.0);
      roll_target = roll_current + (roll_target - roll_current) * adaptive_gain;
  end
  ```

### 3. **実装のメリット**

| 対策 | 効果 |
|------|------|
| EMA平滑化 | 高周波ノイズを除去、後続の処理を安定化 |
| 外れ値検出 | 異常なセンサー値を無視、フィルタ発散を防止 |
| 変化スケーリング | 1.0° 以上の急激な変化を1/10に削減 |
| 適応的ゲイン | 変化の大きさに応じて段階的に制限 |

## 推奨事項

### EMA係数の調整
現在の `ema_alpha = 0.3` は：
- **高い値（0.5~1.0）**: 最新計測値を重視、応答性が高い、ノイズに敏感
- **低い値（0.1~0.2）**: 過去値を重視、ノイズ耐性が高い、応答性が低い

ノイズレベルに応じて調整可能：
```matlab
obj.accel_filter.setEMAAlpha(0.2);  % より強い平滑化
```

### 外れ値閾値の調整
現在は3σで判定。必要に応じて：
```matlab
obj.accel_filter.outlier_threshold = 2.5;  % より厳しい判定
```

### さらなる改善
1. **ノイズレベルに応じた動的 EMA 調整**
   - ノイズが多い時期は α を小さくする
   
2. **状態遷移の検出**
   - 静止状態か運動状態かを自動判定
   - 状態に応じて異なるフィルタ係数を適用

3. **マハラノビス距離による外れ値検出**
   - より高度な統計的判定
