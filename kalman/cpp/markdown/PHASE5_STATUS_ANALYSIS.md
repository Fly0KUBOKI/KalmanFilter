```
総ファイル: 6 個
```

**影響を受けるコンポーネント**:
- ✅ **MEUKF**: 未影響（既に `cmath_fx` に移行）

  - `Eigen::LLT` (Cholesky)

- ❌ **EKF**: 低い依存（未使用）

### 5. 移行後のメリット・デメリット

#### ✅ メリット

| メリット | 効果 | 優先度 |
|---|---|---|
| **外部依存ゼロ化** | ビルド簡素化、配布容易化 | 🔴 高 |
| **ライブラリサイズ削減** | Eigen (~5MB) 廃止 → 実装サイズ小型化 | 🟡 中 |
| **デバッグ容易化** | 自作コードなので修正・カスタマイズ可能 | 🟡 中 |
| **組込み環境対応** | ARM/RISC-V 移植時に依存なし | 🟢 低（将来） |
| **ビルド時間短縮** | Eigen テンプレート展開オーバーヘッド削減 | 🟢 低 |

#### ❌ デメリット / リスク

| リスク | 対策 |
|---|---|
| **数値安定性低下** | Cholesky の pivoting/regularization 実装 |
| **計算性能低下** | SIMD 最適化の検討（将来） |
| **バグ導入の可能性** | ユニットテスト充実、差分検証 |
| **実装期間延伸** | 並列開発、プロトタイピング |

**結論**: メリット >> デメリット。**実施推奨**
