# C++移行成功レポート

## 概要
姿勢推定が崩れていた問題を修正し、C++化を完了しました。

## 問題の根本原因

### 1. 共分散予測における姿勢ダイナミクス項の欠落

**症状**: Pitch, Roll, Yawの推定が完全に崩壊

**原因**: `ESKFCore::predict_covariance` における姿勢-姿勢ブロック（P(7:9, 7:9)）の更新で、回転による誤差伝播項が欠落していました。

#### 修正前（不完全な実装）
```cpp
// ブロック(6:8, 6:8) 姿勢-姿勢
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        P_new(i+6,j+6) = P(i+6,j+6) + dt*(-P(i+6,j+12) - P(i+12,j+6)) + dt2*P(i+12,j+12) + Q(i+6,j+6);
    }
}
```

**問題点**:
- 状態遷移行列 `F` における姿勢誤差の伝播項 `F(7:9, 7:9) = I - [ω]× dt` が実装されていない
- 角速度による回転効果が共分散に反映されない
- これにより姿勢の不確かさが正しく伝播せず、カルマンゲインが異常になる

#### 修正後（完全な実装）
```cpp
// ブロック(6:8, 6:8) 姿勢-姿勢
// F_theta = I - [w]× * dt
Matrix3x3 F_theta;
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        F_theta(i,j) = (i == j ? 1.0f : 0.0f) - skew_w(i,j) * dt;
    }
}

// P_theta_theta = F_theta * P(7:9,7:9) * F_theta'
Matrix3x3 P_theta;
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        P_theta(i,j) = P(i+6,j+6);
    }
}

auto F_P = F_theta * P_theta;
auto F_P_Ft = F_P * F_theta.transpose();

// ジャイロバイアスとのクロス項を含む完全な更新
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        P_new(i+6,j+6) = F_P_Ft(i,j);
        // クロス項: F_theta * P(7:9, 13:15) * (-dt)
        for (int k = 0; k < 3; ++k) {
            P_new(i+6,j+6) += F_theta(i,k) * P(k+6,j+12) * (-dt);
            P_new(i+6,j+6) += (-dt) * P(i+12,k+6) * F_theta(j,k);
        }
        // ジャイロバイアス項: dt^2 * P(13:15, 13:15)
        P_new(i+6,j+6) += dt2 * P(i+12,j+12);
        // プロセスノイズ
        P_new(i+6,j+6) += Q(i+6,j+6);
    }
}
```

**修正内容**:
1. 角速度補正値 `w_corrected` を計算
2. 歪対称行列 `skew_w = [ω]×` を生成
3. 状態遷移行列の姿勢部分 `F_theta = I - [ω]× dt` を構築
4. 完全な共分散更新式を実装: `P_new = F_theta * P * F_theta' + クロス項 + Q`

### 2. 影響範囲の詳細

この欠落により以下の連鎖的な問題が発生していました:

1. **姿勢共分散の不正確な伝播**
   - 回転運動による誤差の増大が考慮されない
   - 共分散が実際より小さく/大きく推定される

2. **カルマンゲインの異常**
   - 不正確な共分散から計算されるゲインが不適切
   - 観測更新（加速度、磁気、GPS）の効果が過大/過小になる

3. **フィルタの不安定化**
   - 誤った信頼度で観測を統合
   - 推定値が真値から乖離し発散

## 技術的詳細

### ESKF状態遷移行列（誤差状態）

完全な状態遷移行列 `F` (15x15):

```
F = [I3  I3*dt   0     0      0    ]  位置
    [0   I3     -R[a]× -R*dt  0    ]  速度
    [0   0   I3-[ω]×dt  0   -I3*dt]  姿勢（修正済み）
    [0   0      0      I3     0    ]  加速度バイアス
    [0   0      0      0      I3   ]  ジャイロバイアス
```

ここで:
- `[a]×`: 加速度の歪対称行列
- `[ω]×`: 角速度の歪対称行列
- `R`: 回転行列（body→world）

### 共分散予測式

```
P_new = F * P * F' + Q
```

姿勢ブロック（7:9, 7:9）の詳細:

```
P_theta_new = F_theta * P_theta * F_theta'
            + F_theta * P(7:9, 13:15) * (-dt)
            + (-dt) * P(13:15, 7:9) * F_theta'
            + dt^2 * P(13:15, 13:15)
            + Q_theta
```
