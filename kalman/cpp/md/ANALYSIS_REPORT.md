# C++化で姿勢推定が崩れた原因の詳細分析

## 問題の症状
- Pitch, Roll, Yawの推定が完全に崩壊
- シミュレーション実行時に姿勢が発散または異常な値に

## 根本原因

### 1. **共分散予測の姿勢ダイナミクス項の欠落（主要原因）**

#### MATLAB実装（正しい）
```matlab
% 姿勢-姿勢 (回転項)
F(7:9, 7:9) = eye(3) - skew_w * dt;
```

#### C++実装（不完全）
```cpp
// ブロック(6:8, 6:8) 姿勢-姿勢
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        P_new(i+6,j+6) = P(i+6,j+6) + dt*(-P(i+6,j+12) - P(i+12,j+6)) + dt2*P(i+12,j+12) + Q(i+6,j+6);
    }
}
```

**問題点**: 
- C++版では姿勢誤差の時間発展項 `(I - [ω]× dt)` が**完全に欠落**
- 姿勢-姿勢の共分散行列が正しく伝播されない
- これにより姿勢の不確かさが異常に増大または縮小し、カルマンゲインが不適切になる

### 2. **影響範囲**

この欠落により以下の問題が発生:

1. **姿勢共分散の伝播が不正確**
   - `P(7:9, 7:9)` の更新が線形近似のみで、回転運動による誤差伝播を無視
   
2. **クロス項の誤差**
   - 姿勢と他の状態量（速度、バイアス）の相関が正しく計算されない
   - 特に `P(4:6, 7:9)` (速度-姿勢) の項が影響を受ける

3. **カルマンゲインの異常**
   - 不正確な共分散行列から計算されるゲインが過大/過小になる
   - 観測更新（加速度、磁気、GPS）が適切に機能しない

4. **推定の発散**
   - フィルタの信頼度が崩れ、最終的に姿勢推定が発散

## 修正方針

### 1. 共分散予測の完全実装
```cpp
// 角速度補正
Vector3 w_corrected = w_meas - bg;

// skew(w)
Matrix3x3 skew_w = kf::KalmanFilterCore::skew_symmetric(w_corrected);

// 姿勢-姿勢ブロック: F(7:9, 7:9) = I - [ω]× dt
Matrix3x3 F_theta;
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        F_theta(i,j) = (i == j ? 1.0f : 0.0f) - skew_w(i,j) * dt;
    }
}

// 共分散更新: P_new(7:9, 7:9) = F_theta * P(7:9, 7:9) * F_theta' + クロス項 + Q
```

### 2. クロス項の正確な計算
- 姿勢-ジャイロバイアス: `F(7:9, 13:15) = -I * dt`
- 姿勢-加速度バイアス: `F(7:9, 10:12)` の項も検証

## その他の潜在的な問題

### Quaternion正規化のタイミング
- C++版では積分後に正規化しているが、頻度が適切か要確認

### 浮動小数点精度
- Float型の使用により、MATLAB（Double）との微小な差が蓄積する可能性
- ただし、これは副次的な問題

## 結論

**主原因**: `predict_covariance` での姿勢誤差伝播項 `(I - [ω]× dt)` の欠落

**影響**: ESKF の共分散行列が正しく更新されず、カルマンゲインが異常になり推定が崩壊

**解決策**: MATLAB版の状態遷移行列 `F` の実装をC++に正確に移植する
