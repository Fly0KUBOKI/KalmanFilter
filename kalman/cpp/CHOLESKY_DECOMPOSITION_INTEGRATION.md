# コレスキー分解の統合

## 実施内容

各フィルタで実装されていたコレスキー分解を`fixed_matrix.hpp`に統合しました。

## 比較結果

### 実装の比較

#### 1. MEUKF (`cholesky3x3`)
- **型**: `Matrix3x3` (3x3固定サイズ)
- **特徴**: 一時配列を使用して実装

#### 2. UKF (`chol_lower_raw`)
- **型**: 生配列 (動的サイズ、最大20x20)
- **特徴**: MEXインターフェース用

#### 3. UKF Core (`cholesky`)
- **型**: `MatrixNN` (テンプレート固定サイズ)
- **特徴**: テンプレート版

#### 4. math_utils (`safe_cholesky`)
- **型**: `FixedMatrix` (動的サイズ)
- **特徴**: 失敗時は単位行列を返す

## 統合方針

各実装のアルゴリズムは本質的に同じであることを確認しました。以下の2つの関数を`fixed_matrix.hpp`に追加しました：

1. **`Matrix<R, C, T>::cholesky()`** - テンプレート版（固定サイズ）
2. **`FixedMatrix::cholesky()`** - 動的サイズ版

## 追加した関数

### `Matrix<R, C, T>::cholesky()`
```cpp
bool cholesky(Matrix<R, C, T>& L) const;
```
- 固定サイズの正方行列用
- 下三角行列`L`を返す（`A = L*L^T`）
- 正定値でない場合は`false`を返す

### `FixedMatrix::cholesky()`
```cpp
bool cholesky(FixedMatrix& L) const;
```
- 動的サイズの正方行列用（ランタイムサイズ、最大20x20）
- 下三角行列`L`を返す（`A = L*L^T`）
- 正定値でない場合は`false`を返す

## アルゴリズム

標準的なコレスキー分解アルゴリズムを使用：
- 下三角行列`L`を計算（`A = L*L^T`）
- 各要素`L(i,j)`を順次計算
- 対角要素: `L(i,i) = sqrt(A(i,i) - sum)`
- 非対角要素: `L(i,j) = (A(i,j) - sum) / L(j,j)`

## 注意事項

- **堅牢版（正則化付き）は実装していない**
  - MEUKFの`cholesky3x3_robust`のような多段フォールバック機能は追加していない
  - 必要に応じて各フィルタで独自に実装可能
  - または、将来`cholesky_robust()`として追加することも可能

- **既存コードへの影響**
  - 各フィルタの既存のコレスキー分解実装はそのまま使用可能
  - 新しく書くコードでは`fixed_matrix.hpp`の`cholesky()`を使用することを推奨

## 次のステップ（オプション）

各フィルタのコードを新しい`cholesky()`関数を使うように更新することも可能ですが、既存コードが動作している場合は無理に変更する必要はありません。
